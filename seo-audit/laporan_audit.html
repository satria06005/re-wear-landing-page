4. Implementasi File Crawling & Indexing

A. File robots.txt (Root Server Vercel)

File ini berhasil dibuat dan ditempatkan di root direktori untuk mengarahkan Googlebot serta menunjuk lokasi peta situs resmi:

User-agent: *
Allow: /

# Sitemap Resmi RE-WEAR
Sitemap: https://re-wear-landing-page.vercel.app/sitemap.xml

B. File sitemap.xml (XML Sitemap Protocol 0.9)

Peta situs XML terstruktur dengan deklarasi canonical URL, tanggal modifikasi berkala, dan prioritas perayapan tertinggi:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://re-wear-landing-page.vercel.app/</loc>
    <lastmod>2026-10-30</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
